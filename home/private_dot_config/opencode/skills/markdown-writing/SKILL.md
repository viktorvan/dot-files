# Markdown writing

This skill is mandatory whenever you create or update Markdown.

## 1. Check necessity

- Identify the reader's task and the information needed to complete it.
- Default to no new file unless the user requests one.
- Otherwise, create a file only if the requested task requires it. Completed work alone is not a reason.

## 2. Write the minimum

- Load and follow the `simplified-technical-english` skill.
- Give necessary facts and direct instructions. Preserve technical accuracy.
- Aim for 20–30 lines or fewer. Exceed 100 lines only in exceptional cases.
- Omit work history, extended reasoning, and narratives about how decisions were reached.
- Do not duplicate information or create extra files to satisfy the length target.

## 3. Review the edit

- Check that each added sentence serves the identified task.
- Apply these rules to your changes, not as a cleanup mandate.
- Do not use this skill to audit existing files or revise unrelated content in files you are editing.
- Preserve existing content unless the user requests its removal or shortening, even when it exceeds the length target.
